# 架构设计文档

## 整体架构

```
┌─────────────────────────────────────────────────────────┐
│                    前端层 (React)                        │
├─────────────────────────────────────────────────────────┤
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐  │
│  │ 连接管理模块  │  │ 查询执行模块  │  │  ETL 模块    │  │
│  └──────────────┘  └──────────────┘  └──────────────┘  │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐  │
│  │ 数据浏览模块  │  │ 结构管理模块  │  │ 监控模块     │  │
│  └──────────────┘  └──────────────┘  └──────────────┘  │
├─────────────────────────────────────────────────────────┤
│              Tauri IPC 通信层 (invoke)                   │
├─────────────────────────────────────────────────────────┤
│                   后端层 (Rust)                          │
├─────────────────────────────────────────────────────────┤
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐  │
│  │ 连接池管理    │  │ 查询引擎     │  │ ETL 引擎     │  │
│  └──────────────┘  └──────────────┘  └──────────────┘  │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐  │
│  │ 数据库适配器  │  │ 数据转换器   │  │ 任务调度器   │  │
│  └──────────────┘  └──────────────┘  └──────────────┘  │
├─────────────────────────────────────────────────────────┤
│                   数据库驱动层                           │
├─────────────────────────────────────────────────────────┤
│  PostgreSQL │ MySQL │ SQLite │ MongoDB │ Redis         │
│  ClickHouse │ TDengine │ SQL Server │ ...              │
└─────────────────────────────────────────────────────────┘
```

## 核心模块

### 1. 连接管理模块
负责数据库连接的配置、测试和管理。

### 2. 查询执行模块
提供 SQL 编辑器和查询执行功能。

### 3. 数据浏览模块
浏览数据库结构和数据内容。

### 4. ETL 模块
实现异构数据源之间的数据同步。

### 5. 监控模块
监控数据库连接状态和任务执行情况。

## 技术选型理由

### 前端
- **React**: 成熟的组件化框架，生态丰富
- **Material UI**: 完整的 UI 组件库，开箱即用
- **Zustand**: 轻量级状态管理，简单易用
- **TanStack Query**: 强大的数据请求和缓存管理

### 后端
- **Tauri**: 轻量级跨平台框架，性能优异
- **Rust**: 内存安全，高性能，适合系统级编程
- **Tokio**: 成熟的异步运行时，适合 I/O 密集型任务

## 数据流

1. 用户在前端界面操作
2. 通过 Tauri IPC 调用后端命令
3. 后端处理业务逻辑，访问数据库
4. 返回结果给前端
5. 前端更新 UI 展示
